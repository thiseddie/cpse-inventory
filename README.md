🤝 Contribution Guidelines
Each team member contributed to the project through their respective tasks. All development work was managed using Git and GitHub to maintain version control and enable effective collaboration.
Create a separate branch for new features or changes.
Use clear and meaningful commit messages.
Pull the latest changes before starting new work.
Test changes before creating a pull request.
Submit changes through a Pull Request for review.
Resolve merge conflicts carefully and keep the main branch stable.
📌 Team Collaboration
